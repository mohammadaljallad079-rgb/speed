## 6. Local fixes performed (with proof)

**Fix 1 — Dashboard monthly-earnings chart (item 16).**

*Defect:* `src/app/dashboard/page.tsx` built the chart with

```ts
months.map((m, i) => ({ value: invoices.filter((i:any) => ...getMonth() === i) ... }))
```

The inner callback parameter `i` (an invoice object) **shadowed** the outer month
index `i`, so `new Date(inv.invoice_date).getMonth() === <invoice object>` was
never true. Every bar rendered **0** regardless of data.

*Proof (standalone reproduction):*

```
CURRENT (buggy): [Jan:0, Feb:0, Mar:0, Apr:0, May:0, Jun:0, Jul:0, Aug:0]
FIXED:           [Jan:0, Feb:0, Mar:270, Apr:0, May:45, Jun:0, Jul:0, Aug:0]
```

*Fix:* rename the outer index to `monthIdx` and the invoice callbacks to `inv`.

*Guard:* `tests/exec42-dashboard-earnings.test.ts` (1 test, passes) asserts the
index is named `monthIdx`, the filter compares to `monthIdx`, and the shadowing
form is absent. The guard was validated against the buggy snippet (it fails there)
and against the fixed file (it passes). Registered in `test:core`.

**Fix 2 — register the new test** in `package.json` `test:core`.

No other change was made. No completed feature was rebuilt.
